# Linux Scripts

A collection of Bash and Linux shell scripts for:

- System administration
- Automation
- Monitoring
- Maintenance tasks

## Structure
- `network/` – networking scripts
- `system/` – system and OS related scripts
- `security/` – hardening and audit scripts
- `utils/` – small helper tools

## Usage
Most scripts are written in Bash.  
Make executable before running:

chmod +x script.sh
